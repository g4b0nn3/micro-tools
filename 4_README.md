# Micro-Tools Online

## How to run locally
1. Put all files (`index.html`, `style.css`, `script.js`) in the same folder.
2. Open `index.html` in your browser.

## How to publish on GitHub Pages
1. Create a public repository on GitHub.
2. Upload all files to the repository.
3. Go to **Settings → Pages** → select **main branch / root**.
4. Click **Save** → your website link will appear.

## Monetization
- Replace the Buy Premium link with your Stripe or PayPal product.
- Use the `unlockPremium()` function to show premium tools after payment.
